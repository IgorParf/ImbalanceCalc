# Приклади вхідних файлів

`sample_month_2026-07.xlsx` — синтетичний зразок місячного файлу гарантованого
покупця (та сама структура з 15 аркушів, але згенеровані дані). Створюється
командою:

```bash
python scripts/make_sample.py
```

Реальні вивантаження від ГП класти в `data/input/` — вони не потрапляють у git.
